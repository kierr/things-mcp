# Contributing

Bug reports and pull requests are welcome on GitHub at
<https://github.com/kierr/things-mcp/issues>.

## Development

1. Install [Bun](https://bun.sh)
2. `bun install`
3. `bun run typecheck` — type-check
4. `bun test` — run tests
5. `bun run build` — build dist

## Pull requests

- Keep changes focused and atomic.
- Run `bun run typecheck && bun test` before pushing.
- New tools or changed behavior should include tests.
